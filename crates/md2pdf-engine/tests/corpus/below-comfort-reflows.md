# Below the comfort floor

Would shrink to 7.5pt — past the point where wrapping reads better — so it reflows instead. Sized so that a comfort floor anywhere above 7.5pt moves it, which is the turnover this fixture pins. The size is a property of the content and the page, not of the base: T30 raised the base from 10pt to 12pt and this table still resolves to the same 7.5pt.
