# AGENTS.md

The authoritative operating instructions for this project live in **`CLAUDE.md`** at the repository root. `CLAUDE.md` is the single source of truth: the working process, the constraints, the conventions, and — for AI Dev Workbench projects — the SDLC.

**If you are an AI coding agent, read `CLAUDE.md` in full and follow it before doing anything else.**

This `AGENTS.md` exists so that tools which look for `AGENTS.md` by convention — OpenAI Codex, Cursor, Windsurf, Aider, Gemini CLI, Amazon Q, and others — find their way to `CLAUDE.md`. It deliberately **points rather than duplicates**, so the two files can never drift apart: when `CLAUDE.md` changes, nothing here has to.

Start here:
- **Instructions, constraints, conventions →** `CLAUDE.md`
- **Project state and what to do next →** `.workbench/` (when present)
